# SKILL #12: EDITING ENGINE

**Layer:** II. EDITORIAL LAYER

**Purpose:** Execute restorative edits: exact-match reductions, source-merges, witness recoveries.

**Governing Mission:** Every removed span has a surviving kept instance; every added span has an authenticated source.

**Scope:** Reductions to band; dedup; recovery seating.

**Inputs:** Chapter + directive + sources.

**Outputs:** Edited text + exact edit log (Exx rows) + before/after counts + hashes.

## Rules

- Reductions remove only exact-duplicate, over-explanation, or pacing-drag text, with kept-instance proof.
- Additions only from authenticated source text belonging to this chapter.
- Death scenes, dialogue outcomes, Spanish spans, and sensory constants untouched.

## Protected Elements

Per the master list (never altered without Gabriel's ruling): character deaths and survivors exactly as recorded; chronology, battle outcomes, and endings; Spanish/Calo and Vietnamese spans with diacritics; the six sensory constants; ceremonial/mystical content; numbering and permanent IDs; all canon-locked clauses. Suspected defects in protected material are FLAG-ONLY.

## Workflow

1. Preflight gate.
2. Mark candidate spans with proofs.
3. Apply.
4. Log each edit with span + rationale.
5. Acceptance package.

**Python/SPSS Integration:** Sequence-diff proofs; dedup detectors.

**Output Template:** Exx | span removed/added | proof | rationale.

## Governance

Gabriel T. Arce makes all canonical and editorial decisions; Claude/TE360 is verifier and builder. The Master Workbook + custody log are the source-of-truth register (custody log governs where the workbook is stale, pending sync). No model self-authorizes canon. RESTORE, NEVER REWRITE. Band 5,600-5,800; never pad. Every operation is preflight-gated, logged, hashed, and acceptance-gated.
