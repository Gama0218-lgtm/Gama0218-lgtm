## 2 · Methodology — how these projections were built

Ch.01's actual certification is the model. The +7.35 lift it produced came from three discrete sources:

| Lift source | Ch.01 contribution | Available to Ch.2-6? |
| --- | ---: | :-: |
| **(a) Artifact deletion**       | +3.00 | only where an artifact is present (Ch.24, Ch.34 in the queue; the opening run is clean) |
| **(b) Certification eligibility bonus** | +5.18 | YES — earned by clearing all 8 benchmarks at strict tolerance |
| **(c) Component lift from revision** | +0.83 | YES — varies by which gaps each chapter carries |
| **Total**                       | **+8.18** (net of components that moved down)| Mean lift Ch.2-6 forecast: **+6.32** |

Per-chapter forecast = baseline Ω + (a) + (b) + (c), with (a) set to zero
when no artifact, and (c) sized to the audited gap from §3 of the audit doc.

Confidence bands:
- **Ch.5 (Ghost Protocol)** — narrowest band, baseline 109 already strongest; certification lift carries most of the projection.
- **Ch.2 (Descent Into Baptism)** — widest band, biggest gaps (CLS −10.92, MRF −11.38); the +7.40 forecast assumes the Spanish-gap remediation works as scoped.
- **Ch.3 (Genocide Algorithm)** — lowest forecast lift (+5.80) because baseline is already strong; CR-1.0 mostly *confirms* what's there rather than building it up.

## Appendix · Projection caveats (the honest version)

- **Ch.01 is the only actually certified chapter.** Everything else in
  Section 1 is a model output.
- **The certification bonus (+5.2 in Ch.01)** is reverse-engineered from
  one observation. The next chapter through CR-1.0 will either confirm
  the +5.2 floor or shift the projection. Plan accordingly.
- **The component-lift estimates** are sized to the audited gaps but
  assume the sprint actions work as scoped — no allowance for revision
  cycles that under-deliver or unexpectedly over-deliver.
- **No projection here changes the live data in `src/lib/chapterScores.js`.**
  Ch.01 is the only chapter in that file at certified values; Ch.2-6 remain
  at v13 baseline. The Ω/CLS Trend tab shows real data only. These
  projections are for sprint planning, not for any agent or award context.

When the real CR workbooks land, the projections retire and the certified
values take their place.
