# SKILL #16: CHARACTER VOICE DNA

**Layer:** II. EDITORIAL LAYER

**Purpose:** Preserve each character's register exactly: diction, rhythm, code-switch pattern, silence.

**Governing Mission:** Voice is canon. A cleaned-up voice is a broken voice.

**Scope:** All dialogue and POV interiority.

**Inputs:** Character register notes + chapter text.

**Outputs:** Voice-consistency report; violations flagged.

## Rules

- Registers locked: Ramos sensor-array (Spanish interior / English command), O'Neil Kentucky, Duc Sorbonne-analytic, Gomez veterano parade-ground Spanish, Sister Marie-Claire DBP-survivor pragmatism, Martinez East L.A. code-switch.
- No modernizing, no softening profanity, no translating what the text leaves untranslated.

## Protected Elements

Per the master list (never altered without Gabriel's ruling): character deaths and survivors exactly as recorded; chronology, battle outcomes, and endings; Spanish/Calo and Vietnamese spans with diacritics; the six sensory constants; ceremonial/mystical content; numbering and permanent IDs; all canon-locked clauses. Suspected defects in protected material are FLAG-ONLY.

## Workflow

1. Extract dialogue per character.
2. Compare against register.
3. Flag drift.
4. Never fix voice without ruling.

**Python/SPSS Integration:** Per-character diction sampling.

**Output Template:** Character | line | drift class.

Gabriel T. Arce makes all canonical and editorial decisions; Claude/TE360 is verifier and builder.
