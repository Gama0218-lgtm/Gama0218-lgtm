# SKILL #07: VERSION CONTROL

**Layer:** I. GOVERNANCE LAYER

**Purpose:** Prevent stale or unproven text from entering the baseline; manage lineages and adoptions.

**Governing Mission:** VERSION_RULE: any text whose hash/word count conflicts with the register is a candidate variant, not the baseline.

**Scope:** All witnesses: master, AutoCrit, Beta, pastes, restored deliverables.

**Inputs:** Candidate text + register (custody log governs where workbook is stale).

**Outputs:** Lineage classification; adoption record (ADJ- entry) when Gabriel rules.

## Rules

- No stale overwrite. No unverified import.
- Name the lineage of every text (master / AutoCrit data-id / Beta span lines / paste).
- Adoption is Gabriel's alone; acceptance gate computes final hash and queues workbook writeback.
- REGISTER DRIFT LESSON (F-21): when workbook and custody log disagree, the later dated log entry governs pending sync.

## Protected Elements

Per the master list (never altered without Gabriel's ruling): character deaths and survivors exactly as recorded; chronology, battle outcomes, and endings; Spanish/Calo and Vietnamese spans with diacritics; the six sensory constants; ceremonial/mystical content; numbering and permanent IDs; all canon-locked clauses. Suspected defects in protected material are FLAG-ONLY.

## Workflow

1. Hash + count candidate.
2. Compare to register.
3. Probe-match against known witnesses.
4. Classify lineage; log.
5. Route adoption to Gabriel.

**Python/SPSS Integration:** Probe-line identity method: endpoints + spread section probes; sequence-diff for near-twins.

**Output Template:** Candidate | lineage | vs register | classification | ruling needed.

## Governance

Gabriel T. Arce makes all canonical and editorial decisions; Claude/TE360 is verifier and builder. The Master Workbook + custody log are the source-of-truth register (custody log governs where the workbook is stale, pending sync). No model self-authorizes canon. RESTORE, NEVER REWRITE. Band 5,600-5,800; never pad. Every operation is preflight-gated, logged, hashed, and acceptance-gated.
