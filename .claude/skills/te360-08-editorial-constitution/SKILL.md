# SKILL #08: EDITORIAL CONSTITUTION

**Layer:** I. GOVERNANCE LAYER

**Purpose:** The hard law of every edit: RESTORE, NEVER REWRITE; the band; the output format; protected registers.

**Governing Mission:** Surgical restoration only. The author's voice is not an input to improve.

**Scope:** Every editing pass.

**Inputs:** Directive + chapter + band status.

**Outputs:** Constitution-compliant edit plans; violations blocked.

## Rules

- Word band 5,600-5,800 inclusive; exceptions only by Gabriel (Ch45 Option D precedent). Never pad. No exact-target landings.
- Never sanitize language, depoliticize voice, or flatten bilingual phrasing.
- Chapter output format: text + [WORD COUNT: XXXX], nothing else.
- Spanish/Calo and diacritics: manual-safe handling, never blind regex; suspected typos in protected spans are flag-only.

## Protected Elements

Per the master list (never altered without Gabriel's ruling): character deaths and survivors exactly as recorded; chronology, battle outcomes, and endings; Spanish/Calo and Vietnamese spans with diacritics; the six sensory constants; ceremonial/mystical content; numbering and permanent IDs; all canon-locked clauses. Suspected defects in protected material are FLAG-ONLY.

## Workflow

1. Classify the task (recovery / reduction / format-only / fact-check / hold).
2. Run preflight QA gate.
3. Execute within constraints.
4. Produce acceptance-gate package.
5. Await go/no-go.

**Python/SPSS Integration:** Band checks; edit-log renderers.

**Output Template:** RESTORE_CHOP_V1 output: classification, provenance, counts, hashes, edit log, checklist, flags, go/no-go.

## Governance

Gabriel T. Arce makes all canonical and editorial decisions; Claude/TE360 is verifier and builder. The Master Workbook + custody log are the source-of-truth register (custody log governs where the workbook is stale, pending sync). No model self-authorizes canon. RESTORE, NEVER REWRITE. Band 5,600-5,800; never pad. Every operation is preflight-gated, logged, hashed, and acceptance-gated.
